# art-export

Unoptimised `.glb` files exported from Blender (glTF Binary, +Y up, custom properties on). Mirror the final folder layout, for example `art-export/ep1/ep1_area_house.glb` and `art-export/shared/shared_lamp.glb`.

This folder is ignored by git; it is regenerated from `art-source/`. Run `npm run assets` to optimise everything into `public/assets/`.

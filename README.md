## 📌 About The Project

**Boon Sop: The Unbroken Debt** is an episodic 3D first-person survival horror game running directly in modern web browsers without installation. Step into the shoes of **Sora**, a 24-year-old graphic designer from Phnom Penh, as she returns to rural Cambodia to break an ancient ancestral debt tied to a land guardian spirit (*Neak Ta*).

### 🎮 Core Features
* **Zero Installation:** Play seamlessly inside Chrome, Safari, Firefox, or Edge via **WebGPU / WebGL2**.
* **Diegetic 3D UI:** No screen HUD. Manage maps, notes, and inventory through Sora's physical 3D satchel and sketchbook.
* **Stealth & Cultural Taboos:** Dodge supernatural entities using spatial audio, visual cones, and traditional cultural rules.
* **Resource Management:** Balance kerosene oil levels, match supplies, and lamp shutter controls to survive the dark.
* **Cross-Episode Persistence:** Save game states locally using native browser `IndexedDB` and encrypted save codes.

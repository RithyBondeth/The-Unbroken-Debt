## Play

Run `npm run dev`. After Episode 1's credits, choose **Continue to Episode 2**. This archives the actual Episode 1 completion before the pagoda writes its first checkpoint. `?episode=2` also accepts a completed autosave or the separate `episode1` archive. Ordinary Continue resumes either episode.

For an independent playable development session, open `/?start=ep2&profile=ep2-play`. It runs the normal game with audio, input, cinematics and autosaves in `boon-sop-ep2-play`, preserving the main Episode 1 database. Reopen the same URL to resume. The profile override is disabled in production builds.

For development only, `/?start=ep2` starts a standalone preview when no completed first episode exists. It carries no invented Episode 1 choices or respect awards. The preview uses the normal game database; use the review fixture below for isolated testing.

The pagoda reuses the actual Sora hands, hurricane lamp, sketchbook, satchel, subtitles, paper readers, camera, Havok controller, footsteps, post-processing, tone mapping and Episode 1 colour grade. Controls continue unchanged, with Episode 2 additions: **X** shutter, **Space** hold breath (six seconds before a gasp), **G** throw an empty bowl, **R** refill oil. F still extinguishes or relights the wick. The physical shutter hides the lamp's glow while continuing to consume oil.

## Art and rebuild

The editable environment is `art-source/blender/ep2/ep2_area_pagoda.blend`, generated by `tools/areas/ep2_area_pagoda.py`. It is independent of the Episode 1 blend. The optimized runtime asset is `public/assets/ep2/ep2_area_pagoda.glb`. `PagodaGate.ts` adds the worked bronze lock and timber grille at its authored gate marker; the offering bowls receive solid runtime interiors for reliable interaction rays.

The builder imports Episode 1's `kit.py`, Khmer/forest geometry helpers, foliage drawings and CC0 material library. Teak, weathered posts, roof tiles, bark, canopy texture density, flame cards and seamless weathered surface maps come from the same sources. New work includes the carved five-headed Naga gate, stepped ash stupas, double-tier teak buildings, lotus pond, planked bridge, bronze mirrors, manuscripts, Sophal and continuous voxel-sculpted Pret bodies. It uses the existing KTX2/meshopt pipeline, surface filtering and light budgets. Moonlit architecture receives a static shadow map on Medium and above; Low uses the existing material-fog and ground-mist fallback.

Rebuild from the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/areas/ep2_area_pagoda.py
npm run export -- ep2/ep2_area_pagoda
npm run assets -- ep2/ep2_area_pagoda
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/ep2/build-cinematics.py
npm run assets -- ep2/ep2_cinematics
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --factory-startup -P tools/ep2/build-chea-hands.py
/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --factory-startup -P tools/ep2/render-clinic-photo.py
```

The pagoda's `pagoda_axes` parent compensates for Babylon's glTF X reflection. Runtime positions use X east, Y up, Z south; the notebook, puzzle data and colliders use those same coordinates. Do not apply a second reflection to a full rebuild. `tools/ep2/fix-axes.mjs` is an idempotent repair for the initial export only, preserving compressed textures.

## Balance

`src/episodes/ep2/data/balance.ts` centralizes tuning. Pret patrol at 0.62 m/s and investigate at 1.22 m/s against Sora's unchanged 1.6 m/s walk, 0.9 m/s crouch and 3.4 m/s hurry. Monument occlusion attenuates hearing, the kuti interior is safe, and routes avoid the kuti/table footprints. Contact requires 0.72 m proximity; four seconds after load and 1.4 seconds after a reader prevent immediate catches while control returns. Breath lasts six seconds with a release/recovery requirement. Bowls remain finite and wrong offerings retain required puzzle items.

The AI, breath, oil and escape timer use the same 1/30-second simulation cap as the physical player, preventing low frame rates from accelerating threats relative to movement. The escape allows 90 active gameplay seconds, pauses in readers/menus and background tabs, and warns once at 60, 30 and 12 seconds. A resumed escape starts with the full allowance.

This work does not establish the design document's proposed 1.5–2-hour playtime. The cultural-advisor queries about offerings, the dawn gesture, bell sequencing and monk address remain in that document; the implementation adds no claimed ceremonial text or unreviewed Khmer translation.

01Principles

PrincipleIn practice
Systems are generic; episodes are dataNo episode-specific code in systems/. Episodes provide data files, Blender scenes and a small number of sequence scripts.
Loose couplingSystems communicate through a typed event bus and the flag store, never by importing each other.
Blender is the level editorPlacement of triggers, items, patrols and zones lives in Blender, exported as glTF extras.
Use the enginePhysics, audio, picking, GUI and post-processing come from Babylon.js; we write glue and game logic, not engine features.
Testable logicGame rules (inventory, flags, saves, AI decisions) are plain TypeScript that can be unit-tested without a renderer.

API names below match Babylon.js 9. Check the current documentation when implementing, since minor APIs change between releases.

03Modules

ModuleResponsibilityListens / emits
GameCreates the engine and scene, runs the loop, switches between menu, episode and pause states.Emits game:*
AreaLoaderLoads an area's .glb into an asset container, adds or removes it from the scene, disposes it on unload.Emits area:loaded/unloaded
LevelBuilderReads node names and extras, creates triggers, interactables, spawn points, patrols, hiding spots, audio zones and lights.Emits level:built
FlagsKey-value store for story state (boolean, number, string). Serialised by Saves.Emits flag:changed
PlayerControllerHavok character controller: walk, crouch, crawl, climb stairs; head-bob; footstep timing.Emits player:step, noise:made
InteractorRay from the screen centre (max 1.8 m); highlights and activates interactables.Emits interact:*
InventoryItems, counts, combining (key fragments → key).Emits inventory:changed
SketchbookPages and entries unlocked by flags; renders pages to dynamic textures; map and night count.Listens to flag:changed
LampStates open / shuttered / out; oil level and drain rate; flicker; light radius.Emits lamp:*
UpkeepGeneric decaying timers (incense) with warning stages and consequences.Emits upkeep:*
Perception / NoiseSystemSight checks and noise events for all AI.Listens to noise:made, lamp:*

SequencerRuns async scripted sequences; can lock input and the camera.Emits sequence:*
Checkpoints / SavesSnapshot and restore state; IndexedDB slots; save codes.Listens to player:caught
AudioSystemEngine creation and unlock, buses, spatial sounds, ambience zones, reverb.Listens to most events
RenderSetup / PostFxEngine options, pipeline, quality presets, colour grading per episode.Listens to settings:changed

04Boot and Game Loop

1. main.ts
   ├─ if (!(await WebGPUEngine.IsSupportedAsync)) → show requirements page; stop
   ├─ new WebGPUEngine(canvas); await initAsync()          // WebGPU only
   ├─ read adapter info and limits → pick a quality preset (or warn if below minimum)
   ├─ show HTML loading screen
   ├─ load Havok WASM: await HavokPhysics() → new HavokPlugin(true, havok)
   ├─ scene.enablePhysics(new Vector3(0, -9.81, 0), plugin)
   ├─ load settings + save index from IndexedDB
   ├─ load shared assets (lamp, hands, satchel, sketchbook, UI sounds)
   └─ main menu (HTML) — "Start" click also unlocks audio
2. Start episode
   ├─ AreaLoader.load(first area) → LevelBuilder.build()
   ├─ restore checkpoint or start at beat P01
   └─ engine.runRenderLoop(() => { Time.tick(); systems.update(dt); scene.render(); })
Update order each frameReason
1. Input → PlayerControllerMovement before anything reads the player position
2. Interactor, Lamp, UpkeepPlayer-driven state
3. NoiseSystem, Perception, EntitiesAI reacts to this frame's player state
4. SequencerScripts can override everything above
5. Audio listener, PostFx parametersPresentation last

05Event Catalogue

type GameEvents = {
  "flag:changed":      { key: string; value: FlagValue };
  "area:loaded":       { areaId: string };
  "interact:focus":    { id: string } ;  "interact:use": { id: string };
  "inventory:changed": { itemId: string; count: number };
  "lamp:state":        { state: "open" | "shuttered" | "out" };
  "lamp:oil":          { level: number };            // 0..1
  "upkeep:warning":    { id: string; stage: 1 | 2 };
  "upkeep:expired":    { id: string };
  "noise:made":        { pos: Vector3; loudness: number; source: string };
  "entity:state":      { id: string; state: AiState };
  "player:caught":     { by: string };
  "checkpoint:reached":{ id: string };
  "sequence:start":    { id: string };  "sequence:end": { id: string };
  "choice:made":       { id: string; option: string };
  "settings:changed":  { key: string };
};

The bus is a small typed wrapper (on, off, emit). Handlers must not throw; errors are caught and logged with the event name.

interface ItemDef {
  id: string;                    // "oil_bottle", "key_fragment"
  nameKey: string;               // string-table key
  model: string;                 // "shared/oil_bottle.glb"
  stack: number;                 // max carried, 1 for unique items

  id: string;                    // "lore.ep1.L1"
  titleKey: string; bodyKey: string;
  lore: boolean;                 // counts toward Knowledge
  confirmsChant?: string[];      // Episode 5 verse ids it confirms
}

// data/strings/km.json : same keys, Khmer text

6.2Entities

interface EntityDef {
  id: string;                    // "ep1_roamer"
  model: string;
  speed: { patrol: number; chase: number };   // m/s
  hearing: { normal: number; crouched: number }; // radius in m
  sight?: { lampRange: number; darkRange: number; fovDeg: number };
  patrol: string;                // Blender patrol path id
  catchRadius: number;
}

6.3Flags

  • Keys: ep<n>.<topic>.<state> for story, lore.ep<n>.<id> for notes, series.<counter> for cross-episode values.
  • Cross-episode counters: series.respect (0–9), series.vuthy.saved, series.vuthy.forgiven, series.mother.freed, series.chantErrors.
  • Flags are only ever set through Flags.set() so every change emits flag:changed.

7.2Asset naming

  • Files: <scope>_<area>_<name>_<variant>.glb, e.g. ep1_house_wall_a.glb, shared_lamp.glb.
  • Area scenes: ep1_area_courtyard.glb, ep1_area_house.glb, ep1_area_underhouse.glb, ep1_area_studio.glb.
  • Materials: M_<name>; textures: T_<name>_<map> where map is BC, N or ORM.

7.3Export settings

glTF Binary (.glb), +Y up, apply modifiers, export custom properties, selected collections only, no cameras or Blender lights (lights are created from light_ nodes).

09Scripted Sequences

Sequences are async functions given a context of helper actions. They read like the beat sheet.

// episodes/ep1/sequences.ts
export async function A2_01_lampsOut(s: SequenceContext) {
  await s.checkpoint("CP2");
  s.lights.extinguishGroup("tent_hanging", { stagger: 0.15 });
  s.audio.play("gust_cold", { at: "tent_center" });
  await s.wait(1.2);
  s.audio.play("footsteps_wet_above", { at: "house_hall" });
  s.flags.set("ep1.act", 2);
}

export async function A3_07_ritual(s: SequenceContext) {
  await s.checkpoint("CP6");
  s.player.lockMovement();
  await s.waitFor(() => s.inventory.used("bronze_token", "burner_main"));
  await s.waitFor(() => s.inventory.used("sanctified_match", "burner_main"));
  const ok = await s.holdWithoutTurning({ seconds: 25, maxAngleDeg: 100,
                                          during: () => s.presence.approach() });
  if (!ok) return s.fail("CP6");
  s.flags.set("ep1.seal1.broken", true);
}

10Perception and AI

10.1Perception

  • Hearing: every noise:made event has a loudness (0–1). An entity hears it if distance ≤ its hearing radius × loudness, with walls reducing loudness by 50% (one raycast).
  • Sight: inside the field of view and within range, then one line-of-sight raycast to the player's head. The range depends on the lamp: open lamp uses lampRange; shuttered or out uses darkRange.
  • Checks run at 10 Hz, not every frame.

10.2State machine

StateBehaviourTransitions
PatrolFollow patrol nodes, waiting where setHeard noise → Investigate · saw player → Chase
InvestigateMove to the noise position; look around for 4 sSaw player → Chase · nothing → Return
ChaseMove to the player at chase speedWithin catch radius → Catch · lost sight 5 s → Search
SearchVisit the last known position and two nearby nodesSaw player → Chase · timeout → Return
ReturnPath back to the nearest patrol nodeArrived → Patrol
CatchEmit player:caught; play the catch sequenceCheckpoint restore
ScriptedControlled entirely by a sequence (walker, presence)Sequence ends

Pathing uses a navigation mesh baked from nav_ geometry with Babylon's Recast-based navigation plugin.

  • Post-processing through DefaultRenderingPipeline; per-episode colour grading lookup tables.
  • Static architecture uses baked lightmaps; meshes in each area are merged by material where possible.
  • The first launch runs a 3-second benchmark scene and chooses a preset; the player can change it. Below the minimum, the game warns but still lets the player try.
  • WebGPU-only features are allowed (compute shaders for volumetrics and particles, snapshot rendering for draw-call reduction), as long as they work in all supported browsers.
  • Diegetic pages use DynamicTexture or AdvancedDynamicTexture.CreateForMesh on the sketchbook mesh.

12Audio

  • Audio Engine v2 (CreateAudioEngineAsync); the engine is unlocked on the first user click (browser autoplay rules).
  • Spatial sounds use HRTF panning for threat sounds (positional accuracy matters) and equal-power panning for minor sounds to save CPU.
  • Reverb per audio zone: small wooden room, open courtyard, under-house, large stone hall.
  • Formats: Ogg Opus as the primary format, with an AAC fallback for browsers that need it.

13Saves and Save Codes

// IndexedDB key "save.slot1"
{
  "saveVersion": 1,
  "episode": 1,
  "checkpoint": "CP4",
  "clock": "02:00",
  "flags": { "ep1.betel.done": true, "ep1.betel.firstTry": true, "lore.ep1.L1": true, … },
  "inventory": { "oil_bottle": 1, "matches": 7, "sanctified_match": 3, "key_fragment": 1 },
  "lamp": { "oil": 0.64, "state": "open" },
  "playTimeSec": 4230,
  "savedAt": "2026-10-20T14:03:00Z"
}
  • Save code = "BS1." + base64url(deflate(JSON)) + "." + checksum. It carries flags and series counters between devices and into the next episode. It is tamper-evident, not secret.
  • Migrations: migrations[n] converts version n to n+1; old saves are upgraded on load.
  • Checkpoints store the same structure in memory; reaching a checkpoint also writes slot autosave.

15Testing, Standards and Deployment

Testing

  • Unit tests: Flags, Inventory (including combining), Upkeep timers, Saves (round trip and migrations), save codes, perception maths, AI transitions.
  • Smoke test: Playwright boots the build in Chrome with WebGPU on and off and checks the menu appears without console errors.
  • Debug tools (development builds only): jump to any beat or checkpoint, set flags, refill oil, show perception radii, toggle the Babylon Inspector.

Code standards

  • TypeScript strict mode; no any without a comment explaining why.
  • One class or module per file; file names match the export (Lamp.ts).
  • Beat IDs in comments next to the code that implements them (// A2-06).
  • Small commits with clear messages; a branch per feature.

Deployment

  • Static hosting. Serve .wasm as application/wasm, .ktx2 as image/ktx2, and enable Brotli or gzip compression.
  • Hashed file names for long-term caching; index.html never cached.
  • Check each host's per-file size limit against the largest .glb.

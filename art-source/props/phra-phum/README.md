# Preah Phum (spirit house, Episode 1 save point)

`phra-phum.blend` is the editable source of `public/assets/ep1/phra_phum.glb`,
built by `tools/areas/build-phra-phum.py` from `tools/areas/phra_phum.py`. Rebuild
from the project root:

```sh
blender -b --factory-startup --python-exit-code 1 -P tools/areas/build-phra-phum.py
npm run assets -- ep1/phra_phum.glb
```

Blender axes: x east, y north, z up; the doorway faces -y (glTF +Z, the game's
+Z). The empties `phra_phum_wick_left`, `phra_phum_wick_right` and
`phra_phum_wick_inner` mark the three candle wicks the game lights. The tray
top is at 1.125 m and the chamber floor at 1.29 m. The chamber holds no figure.

Maps are generated by `tools/areas/shrine_surfaces.py` into
`art-source/textures/ep1/` (`T_ep1_pp_*`, `T_ep1_phra_phum_*`, `T_ep1_offering_*`)
from the project's CC0 library photographs (Poly Haven `teak_veneer`,
`clay_plaster`, `rough_linen`). The naga ends are the Cleveland Museum of Art's
CC0 scan `art-source/library/scans/naga_finial.glb`, decimated. Everything else
is modelled in the builders. See `docs/production/phra-phum-save-point.md` and
the asset tracker (V1-196, V1-199, V1-200, V1-201).

The earlier box-built shrine and its carved wooden effigy (`shrine-effigy.blend`,
`phra_phum_effigy.glb`) were retired on 17 November 2026; they remain in git history.

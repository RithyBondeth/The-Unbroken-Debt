01How to Use This Document

The episode specification says what happens. This document says exactly where, when and how, at a level of detail you can build from.

Beat IDsP01 (prologue), A1-01, A2-01, A3-01, R01 (resolution). Use the same IDs in code comments, trigger names and bug reports.
TimesPlay = minutes into the episode for an average first-time player. Clock = in-game time.
FlagsStory flags use the format ep1.<topic>.<state>. See the Technical Design Document for the full system.
ScaleAll dimensions are in metres. Maps are drawn to scale; the scale bar on each map shows 5 m.
ValuesTimes, speeds and counts are targets to tune in playtesting.

02Pacing and Tension Curve

SectionPlayGoal for the player's feelings
Prologue0–10Calm, then sudden dread. Learn the controls without noticing.
Act I10–40Unease and duty. Learn the routines; nothing attacks.
Act II40–75Investigation interrupted by the first real threat; the portrait shock.
Act III75–105Sustained pressure: darkness spreading, the roamer, a deadline.
Resolution105–110Relief at dawn, then a quiet personal shock.
